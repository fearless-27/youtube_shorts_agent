# GhostPipe Manual Improvements & Expansion Guide

This guide covers step-by-step instructions for implementing advanced features that require external accounts or API configurations.

## 1. Telegram / Discord Bot Instant Notification System

Receive immediate push notifications on your phone whenever a new Short is generated, with 1-click `[Approve]` and `[Reject]` actions.

### Architecture
```
[GhostPipe Pipeline] 
     │ (renders Short)
     ▼
[Webhook Dispatcher] ──▶ [Telegram / Discord Bot API] ──▶ [Your Phone]
     ▲                                                         │
     └──────── (Webhook Callback / Inline Button) ─────────────┘
```

### Setup Steps for Telegram:
1. **Create Bot**:
   - Open Telegram and message `@BotFather`.
   - Send `/newbot`, name it (e.g., `GhostPipeAgentBot`), and save the `TELEGRAM_BOT_TOKEN`.
2. **Get Chat ID**:
   - Message `@userinfobot` to get your numeric `CHAT_ID`.
3. **Add to `.env`**:
   ```env
   TELEGRAM_NOTIFIER_BOT_TOKEN=123456789:ABCdef...
   TELEGRAM_NOTIFIER_CHAT_ID=987654321
   ```
4. **Python Dispatch Snippet (in `pipeline/api_integrations.py`)**:
   ```python
   import requests

   def notify_clip_ready(title, virality_score, preview_url, approval_id):
       bot_token = os.getenv("TELEGRAM_NOTIFIER_BOT_TOKEN")
       chat_id = os.getenv("TELEGRAM_NOTIFIER_CHAT_ID")
       if not bot_token or not chat_id:
           return
       
       text = f"🎬 *New Short Ready for Approval*\n\n*Title*: {title}\n*Virality*: {virality_score}/10"
       reply_markup = {
           "inline_keyboard": [[
               {"text": "✅ Approve", "callback_data": f"approve:{approval_id}"},
               {"text": "❌ Reject", "callback_data": f"reject:{approval_id}"}
           ]]
       }
       requests.post(
           f"https://api.telegram.org/bot{bot_token}/sendMessage",
           json={"chat_id": chat_id, "text": text, "parse_mode": "Markdown", "reply_markup": reply_markup}
       )
   ```

## 2. Multi-Platform Syndication (TikTok & Instagram Reels)

All Shorts generated by GhostPipe are already vertical 9:16 MP4s under 60 seconds with burned-in captions — perfectly compliant with TikTok and Instagram Reels.

### A. TikTok Content Posting API
- **Requirements**: TikTok Developer Account + App approved for `video.upload`.
- **Workflow**:
  1. POST video chunks to `https://open.tiktokapis.com/v2/post/publish/creator_info/query/`.
  2. Send metadata (title, sound, privacy level).
  3. Monitor upload status via `publish_id`.

### B. Instagram Reels via Meta Graph API
- **Requirements**: Instagram Professional / Creator Account linked to a Facebook Page.
- **Workflow**:
  1. Initialize container:
     ```http
     POST https://graph.facebook.com/v19.0/{ig-user-id}/media
     ?media_type=REELS
     &video_url={PUBLIC_PREVIEW_URL}
     &caption={TITLE_AND_HASHTAGS}
     &access_token={PAGE_ACCESS_TOKEN}
     ```
  2. Publish container after processing:
     ```http
     POST https://graph.facebook.com/v19.0/{ig-user-id}/media_publish
     ?creation_id={CONTAINER_ID}
     &access_token={PAGE_ACCESS_TOKEN}
     ```

## 3. Storage Garbage Collection (Disk Cleaner)

To prevent `downloads/` and `outputs/` from consuming tens of gigabytes:

### Automated Pruning Script
You can schedule a weekly cleanup in Windows Task Scheduler or add a Node.js cron:
```javascript
// server.mjs periodic cleanup (older than 7 days)
import { readdirSync, statSync, unlinkSync } from "node:fs";

function cleanOldFiles(dir, maxAgeDays = 7) {
  const maxAgeMs = maxAgeDays * 24 * 60 * 60 * 1000;
  const now = Date.now();
  for (const file of readdirSync(dir)) {
    const p = join(dir, file);
    try {
      const stats = statSync(p);
      if (stats.isFile() && (now - stats.mtimeMs) > maxAgeMs) {
        unlinkSync(p);
        console.log(`[CLEANUP] Deleted old file: ${file}`);
      }
    } catch {}
  }
}
```

## 4. YouTube API Multi-Credential Rotation

If you hit the 10,000 unit daily quota (~6 uploads/day):
1. In [Google Cloud Console](https://console.cloud.google.com/), create a second project (e.g. `GhostPipe-Backup`).
2. Enable YouTube Data API v3 and generate `client_secrets_2.json`.
3. In `pipeline/api_integrations.py`, add a retry handler:
   ```python
   try:
       upload_to_youtube(credentials="client_secrets.json")
   except HttpError as e:
       if "quotaExceeded" in str(e):
           print("[WARN] Primary YouTube quota exceeded, switching to secondary credentials...")
           upload_to_youtube(credentials="client_secrets_2.json")
   ```
